## 1. Input and Output with Function Machines

### What does this mean?
A **function machine** takes an input number, applies one or more mathematical operations in order, and gives an output.

![Diagram: Function machine taking input x, multiplying by 3, then adding 4 to give output y](/maths-images/Y7/02-function-machine.png)

---

### Method

#### Finding Output given Input:
Follow the operations from **left to right**.

#### Finding Input given Output:
Work backwards from **right to left** applying **inverse operations**:
* Addition ($+$) $\leftrightarrow$ Subtraction ($-$)
* Multiplication ($\times$) $\leftrightarrow$ Division ($\div$)

---

### Worked Example

**Question:**
A function machine has operations $[\times 3] \rightarrow [+ 4]$.
1. Find the output if the input is $5$.
2. Find the input if the output is $25$.

**Answer:**
1. Forward: $5 \times 3 = 15 \rightarrow 15 + 4 = \mathbf{19}$
2. Backward: Reverse operations $[- 4] \rightarrow [\div 3]$.
   * $25 - 4 = 21 \rightarrow 21 \div 3 = \mathbf{7}$

Answer: **1) $19$, 2) $7$**
