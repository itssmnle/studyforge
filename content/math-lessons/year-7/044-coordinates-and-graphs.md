## 1. Coordinates in 4 Quadrants

### What does this mean?
A coordinate pair $(x, y)$ gives the position of a point on a grid relative to the **origin** $(0,0)$.
* $x$: Horizontal distance (along the corridor).
* $y$: Vertical distance (up the stairs).

![Diagram: Four quadrant Cartesian graph showing axes x and y crossing at origin (0,0) with labeled Quadrants I, II, III, IV](/maths-images/Y7/15-coordinates-four-quadrants.webp)

---

### Method
1. Start at the origin $(0,0)$.
2. Move left (-) or right (+) along the horizontal $x$-axis.
3. Move down (-) or up (+) along the vertical $y$-axis.
4. Write as $(x, y)$ inside brackets with a comma.

---

### Worked Example

**Question:** Plot point $A(-3, 4)$.  
**Answer:** From $(0,0)$, move $3$ units **left** and $4$ units **up**.

## 2. Straight-Line Graphs ($y = mx + c$)

### What does this mean?
Any straight-line graph can be written in the form:

$$y = mx + c$$

* $m$ = **gradient** (steepness of the line)
* $c$ = **$y$-intercept** (where the line crosses the vertical $y$-axis)

---

### Method
1. Set up a table of values for chosen $x$-values (e.g., $x = 0, 1, 2, 3$).
2. Substitute each $x$-value into the equation to calculate $y$.
3. Plot the $(x, y)$ pairs on a coordinate grid and join them with a single straight line.

---

### Worked Example

**Question:** Plot $y = 2x + 1$ for $x = 0, 1, 2$.

**Answer:**
* When $x = 0 \rightarrow y = 2(0) + 1 = 1 \rightarrow (0, 1)$
* When $x = 1 \rightarrow y = 2(1) + 1 = 3 \rightarrow (1, 3)$
* When $x = 2 \rightarrow y = 2(2) + 1 = 5 \rightarrow (2, 5)$

Answer: **Plot points $(0,1), (1,3), (2,5)$ and draw a line through them.**
