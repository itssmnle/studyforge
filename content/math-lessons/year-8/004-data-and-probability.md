## 1. Two-Way Tables and Grouped Frequency

### What does this mean?
A **two-way table** categorises data under two different variables simultaneously using rows and columns.

![Diagram: 2x2 Two-way table showing Boys/Girls vs Spanish/French with total rows and columns](/maths-images/Y8/two-way-table-boys-girls-languages.png)

---

### Method
1. Ensure the sum of each row equals the row total.
2. Ensure the sum of each column equals the column total.
3. The grand total in the bottom-right corner must equal the total number of items/people sampled.

---

### Worked Example

**Question:**
In a group of $30$ students, $12$ are boys. $8$ boys and $9$ girls study French. Complete the table to find how many girls do NOT study French.

**Answer:**
* Total girls $= 30 - 12 = 18$
* Girls studying French $= 9$
* Girls not studying French $= 18 - 9 = 9$

Answer: **$9$ girls**

## 2. Venn Diagrams and Set Notation

### What does this mean?
A **Venn diagram** represents sets of data visually using overlapping circles inside a universal set ($\xi$).
* **Intersection ($A \cap B$):** Items in **both** set $A$ AND set $B$ (overlapping central section).
* **Union ($A \cup B$):** Items in set $A$ OR set $B$ OR both (everything inside circles).
* **Complement ($A'$):** Items **NOT** in set $A$ (everything outside set $A$).

![Diagram: Venn diagram showing Set A and Set B intersecting inside universal set square, highlighting intersection A n B](/maths-images/Y8/venn-diagram-intersection.png)

---

### Method
1. Fill in the **intersection ($A \cap B$)** first.
2. Fill in the remaining parts of Set $A$ and Set $B$.
3. Write values that belong to neither set in the outside region of the rectangle.

---

### Worked Example

**Question:**
$\xi = \{1, 2, 3, 4, 5, 6, 7, 8\}$, Set $A = \{\text{Evens}\}$, Set $B = \{\text{Multiples of } 4\}$. Find $A \cap B$.

**Answer:**
* Set $A = \{2, 4, 6, 8\}$
* Set $B = \{4, 8\}$
* Common elements ($A \cap B$) $= \{4, 8\}$

Answer: **$A \cap B = \{4, 8\}$**

> [!INFO] **Examiner Tips and Tricks**
> Remember: $\cap$ means **Intersection** ("and" / middle overlapping part), while $\cup$ means **Union** ("or" / all elements in both circles combined).
