## 1. Atomic Structure and Notation

### What does this mean?
Atoms consist of a central nucleus containing **protons** and **neutrons**, surrounded by **electrons** in energy shells.

| Particle | Relative Mass | Relative Charge |
| :--- | :--- | :--- |
| **Proton** | $1$ | $+1$ |
| **Neutron** | $1$ | $0$ |
| **Electron** | $\frac{1}{1840}$ (negligible) | $-1$ |

![Diagram: Atomic notation diagram showing Mass Number A (top) and Atomic Number Z (bottom) next to chemical symbol X]

---

### Method
For an atom written as ${}_{Z}^{A}\text{X}$:
* **Proton Number ($Z$):** Number of protons = Number of electrons in a neutral atom.
* **Mass Number ($A$):** Total number of Protons + Neutrons.
* **Neutrons:** $\text{Mass Number } A - \text{Proton Number } Z$.
* **Electronic Configuration:** Shell maximums $= 2, 8, 8$.

---

### Worked Example & Answer

**Question:**
Determine the subatomic particles in an atom of Chlorine-37 (${}_{17}^{37}\text{Cl}$).

**Answer:**
* Protons $= Z = 17$
* Electrons $= Z = 17$
* Neutrons $= A - Z = 37 - 17 = 20$
* Electronic configuration $= 2, 8, 7$

Answer: **$17$ Protons, $17$ Electrons, $20$ Neutrons**

> [!INFO] **Examiner Tips and Tricks**
> **Isotopes** are atoms of the same element with the same number of protons ($Z$) but different numbers of neutrons ($A$). Isotopes have **identical chemical properties** because they have the same electronic configuration!

## 2. Elements, Compounds, Mixtures, and the Periodic Table

### What does this mean?
* An **element** contains one type of atom.
* A **compound** contains different elements chemically bonded in fixed proportions.
* A **mixture** contains substances that are not chemically bonded and can be separated physically.

For elements 1–20, electrons fill shells $2,8,8$. The **group** gives the number of outer-shell electrons, while the **period** gives the number of occupied shells. Ions form when atoms gain or lose electrons; the nucleus does not change.

![Diagram: Periodic table extract for elements 1 to 20 showing groups, periods, and electron configurations]

### Method
1. Write the electron configuration.
2. Count occupied shells to find the period.
3. Count outer-shell electrons to find the group.
4. For an ion, add electrons for a negative charge or subtract them for a positive charge.

### Worked Example & Answer

**Question:** An atom has electron configuration $2,8,2$. State its group and period, and predict its ion.

**Answer:** It has two outer electrons, so it is in Group 2. It has three occupied shells, so it is in Period 3. It loses two electrons to form a $2+$ ion.

> [!INFO] **Examiner Tips and Tricks**
> A mixture has no fixed formula. A compound has a fixed ratio and can only be separated by chemical means.
